# Verified experiment artifacts

These files record the full NIH ChestXray14 experiments completed on August 22, 2026 using an
NVIDIA A100-SXM4 80 GB GPU, PyTorch 2.11, and CUDA 12.8.

The tracked artifacts include:

- aggregate test metrics for DenseNet-121 and ViT-B/16;
- disease-level test metrics and validation-selected thresholds;
- per-epoch training histories;
- the audited patient-disjoint split summary;
- ROC, precision-recall, training-history, and disease-level figures;
- twelve DenseNet-121 Grad-CAM examples generated from the held-out test set;
- aggregate and disease-level model-comparison figures.

The final checkpoints, cached split manifests, and test prediction matrices are excluded because
of their size. They remain reproducible through the experiment configurations and Colab notebook.

The `comparison` tables and figures are generated by `scripts/compare_models.py` from each
experiment's saved evaluation output. Machine-readable files preserve the full-precision values
produced by the completed runs; the main README rounds results to four decimal places for
readability.
